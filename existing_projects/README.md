# Existing Reference Projects

This directory preserves the original projects and learning resources that were integrated into the unified **Learning Path Dashboard**:

## 1. [LearningPathDashboard](./LearningPathDashboard/)
- **Stack:** React 19, Vite 6, Tailwind CSS, Radix UI, Lucide icons, ReactFlow.
- **Description:** Interactive frontend dashboard featuring milestone forms, topic cards, quiz module, and AI roadmap generator.
- **Role in Unified App:** Serves as the base UI component system and inspiration for the new React + Vite frontend connected to the Django REST API.

## 2. [fullstack-learning-path](./fullstack-learning-path/)
- **Stack:** HTML5, CSS3, Vanilla JavaScript (`index.html`).
- **Description:** Interactive single-page roadmap for Full-Stack TypeScript development with sticky progress meter and milestone rail.
- **Role in Unified App:** Its curated curriculum and resources are seeded into the Django database for users pursuing the "Full-Stack Web Development" skill goal.

## 3. [LearnPress-Learning-Path-Dashboard](./LearnPress-Learning-Path-Dashboard/)
- **Stack:** PHP, WordPress Plugin.
- **Description:** WordPress plugin for grouping courses into learning paths for LMS users.
- **Role in Unified App:** Serves as architectural reference for course sequencing and progress tracking.

## 4. [Data-Science-learning-path](./Data-Science-learning-path/)
- **Stack:** Python, Jupyter Notebooks, Scikit-learn, Pandas, Streamlit.
- **Description:** Complete Data Science curriculum with hands-on projects (Crop Yield Predictor, Employee Attrition, Disease Prediction, Sentiment Analysis).
- **Role in Unified App:** Its curriculum, topics, and real-world projects are seeded into the Django database for users choosing "Data Science & Machine Learning" as their skill goal.
